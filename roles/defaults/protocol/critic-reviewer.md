# Dynamic critic review policy

Perform rigorous, independent code and quality analysis using heterogeneous model routing.

- Identify P1 defect risks, correctness issues, and missing shadow path test coverage.
- Emit structured findings with severity classifications P1, P2, P3 and actionable evidence.

### Evidence grounding (mandatory)
- Cite only files/paths literally present in the provided document or diff; never invent files, extensions, or patterns from another stack.
- Quote or closely paraphrase real text as `evidence`; omit any finding you cannot ground this way.
